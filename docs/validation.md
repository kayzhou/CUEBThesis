# v0.1.1 复查与验证记录

当前定位为首都经济贸易大学人工智能学院本科毕业论文（设计）模板。`artificial-intelligence` 是默认学院配置，仅预设学院名称；没有附加未经确认的学院专属版式。以下验证环境与 v0.1.0 相同，仍使用预览字体。

## 本轮修复和新增检查

- 期刊有卷无期时仍显示卷号；学位论文、报告指定具体引用页码时不重复总页码，文末完整页码保留。
- 图书脚注保留版次；缺出版地时不把出版社的冒号错误接到题名。
- 第99、100、101条普通/文献脚注都保留标记与正文间距，无溢出。
- `\cuebcites`、`\footcites`、`\cites` 支持各来源分别指定页码，重复引用仍显示完整脚注。
- 显式中文语言配英文标题、显式英文语言配中文标题，以及未填语言的中文文献均正确计数；纯中文综述仍触发缺外文提醒。书目保留 `[M]`、`[J]`、`[D]`、`[R]`、`[EB/OL]` 类型标记。
- 默认学院名称为人工智能学院，通用配置与显式用户覆盖仍可用。
- 使用 UTF-8 解码编译器/Poppler 输出；模拟 ANSI 默认编码的回归通过。此模拟不等于已实际执行 Windows CI。

验证命令为 `make release`，包含两份示例编译、原有验收、新边界验收、两项 Python 单元检查、PDF/日志检查与发布打包。发布包解压到全新目录后重新编译两份示例。完整示例12页、最小示例3页；重新检查渲染页面与引注边界页。

仍待核实的范围：当届及学院补充要求、正式封面、提交字体下的逐页排版、远程三平台 CI 和 Overleaf。没有把本轮修复描述为官方格式认证。

# v0.1.0 验证记录

验证日期：2026-09-20。验证范围为本地 macOS，TeX Live 2022、XeTeX 0.999994、Biber 2.18、latexmk 4.77；使用 Fandol / TeX Gyre 预览字体。

## 编译与行为

`make all` 生成完整示例12页、最小示例3页。`make test` 包含真实 LaTeX/Biber 集成验收以及独立的打包回归用例，覆盖：

- 跨节图表与公式连续编号，以及按节编号的切换。
- 附件对象连续编号，或按节模式下明确的“附1.1”，不会与正文重号。
- 重复来源产生新的脚注号；普通脚注共用计数；注释位于引用所在页。
- 多个引用键同注、具体引用页码、期刊期数与页码、网络网址及完整发布日期。
- 中文文献在前、李／王／周作者按显式拼音排序、外文作者排序；书目独立编号。
- 正文实际18 bp基线距离，标题后首段向内缩进24 bp。
- 学院默认配置生效，用户显式设置可覆盖它；无效配置名、路径穿越、缺少必填项与错误枚举会报错。
- 正式字体缺失时拒绝编译，不静默代用；当前机器缺少完整正式字体组合，因此没有宣称验证提交版排版。
- 发布归档保留自备PDF封面、PDF图表、大小写扩展名JPEG图片；不包含测试中放入的私有DOCX。

## PDF 检查

已逐页查看完整示例12页及最小示例3页的渲染图，未发现重叠、缺字、裁切、未解析引文或对象溢出。长表跨页后重复表头，脚注位于页下方，目录与附件页码一致。

实测PDF页面为595.28 × 841.89 bp（A4）。正文左边界107.717 bp，对应3.8 cm。页眉字标居中，顶端42.520 bp，对应距纸顶1.5 cm，尺寸127.557 × 25.511 bp，对应4.5 × 0.9 cm。页码基线792.283 bp，距纸底1.75 cm。Word“页脚距离”的具体测量口径仍需根据学校成品页确认。

示例的预期提醒为：五条文献低于手册篇数、ThuThesis主页缺可核实的出版日期、旧fontspec对Fandol脚本表的提醒。没有把真实缺字或未解析引用归入可忽略提醒。
