# v0.1.0 验证记录

验证日期：2026-09-20。验证范围为本地 macOS，TeX Live 2022、XeTeX 0.999994、Biber 2.18、latexmk 4.77；使用 Fandol / TeX Gyre 预览字体。

## 编译与行为

`make all` 生成完整示例12页、最小示例3页。`make test` 包含真实 LaTeX/Biber 集成验收以及独立的打包回归用例，覆盖：

- 跨节图表与公式连续编号，以及按节编号的切换。
- 附件对象连续编号，或按节模式下明确的“附1.1”，不会与正文重号。
- 重复来源产生新的脚注号；普通脚注共用计数；注释位于引用所在页。
- 多个引用键同注、具体引用页码、期刊期数与页码、网络网址及完整发布日期。
- 中文文献在前、李／王／周作者按显式拼音排序、外文作者排序；书目独立编号。
- 正文实际18 bp基线距离，标题后首段向内缩进24 bp。
- 学院默认配置生效，用户显式设置可覆盖它；无效配置名、路径穿越、缺少必填项与错误枚举会报错。
- 正式字体缺失时拒绝编译，不静默代用；当前机器缺少完整正式字体组合，因此没有宣称验证提交版排版。
- 发布归档保留自备PDF封面、PDF图表、大小写扩展名JPEG图片；不包含测试中放入的私有DOCX。

## PDF 检查

已逐页查看完整示例12页及最小示例3页的渲染图，未发现重叠、缺字、裁切、未解析引文或对象溢出。长表跨页后重复表头，脚注位于页下方，目录与附件页码一致。
