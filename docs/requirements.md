# 规范映射与核对记录

版本：`cueb-2024`；实现：v0.1.1 预览版；记录日期：2026-09-20。

## 依据与效力

依据用户提供的《4-本科毕业论文(设计)指导与评审手册+格式撰写要求（参考）.docx》，封面标注二〇二四届。主要定位为《首都经济贸易大学本科毕业论文（设计）撰写要求》及末尾“内容—示例—要求”表。未把其中已填写的学生报告、指导记录或手册封面当作论文版式底稿。原始文件含个人资料，不随项目分发。

这是依据特定材料实现的社区模板。经确认适用的当届学校文件和学院补充文件优先；表中“实现”描述排版机制，不能替代对最终提交 PDF 的审定。

## 条款与实现

| 项目 | 手册条款或示例 | 本版实现与核对方式 |
| --- | --- | --- |
| 组成 | 封面、中英文摘要、目录、正文、参考文献、附件、致谢；另有打印扉页要求 | 主文件列出所需组成；正式封面须外部提供，自动扉页为暂拟重建 |
| 正文字数 | 中文一般8000～10000字；外文一般5000～10000单词 | 主示例为缩短演示，不满足该要求；最终统计以学校口径为准 |
| 中文摘要 | 约300～500字 | 独立摘要环境；作者核对篇幅与实际分页 |
| 关键词 | 3～5个，摘要页最下方另起一行 | `\cuebkeywords` 放在摘要环境内；中英文分别填写 |
| 标题编号 | `1`、`1.1`、`1.1.1`，一般不超过三级，左齐，编号后空一个汉字距 | 使用 section / subsection / subsubsection，统一控制样式 |
| 标题字体 | 一级黑体小三；二级黑体小四；三级宋体小四 | 文档类集中设定 |
| 正文 | 中文宋体小四；英文 Times New Roman 12磅；两端对齐；首行缩进两字 | 正式模式指定字体；预览模式明确代用；正文12 bp |
| 行距 | 1.5倍 | 本版以18 bp基线距离为待校准解释，不宣称等同于所有 Word 1.5倍设置 |
| 前置部分与文献标题 | 黑体小三，内容宋体小四 | 环境及标题命令统一生成 |
| 图表 | 图题在下、表题在上；居中；宋体五号；编号与题名空两格 | 示例与类共同落实位置和格式，人工查看长题名换行 |
| 公式 | 括号编号靠右，无虚线 | amsmath 自动计数与引用 |
| 编号范围 | 正文要求图表公式全文连续；末表出现按节编号示例 | 默认 `continuous`；可选 `section`，冲突见下表 |
| 引注 | 当页脚注；上角标方括号数字；全文连续；宋体小五 | `\cuebcite` 与普通 `\footnote` 共用连续计数 |
| 文末文献 | 中文在前，外文在后；作者拼音/字母顺序；GB/T 7714—2005 | 独立 bibliography 样式基于2005样式；中文必须核对显式 `sortkey` |
| 页码信息 | 文末可不标起止页码，脚注示例保留引用页码 | 保留已有书目页码，引用处通过可选参数填写核实的具体页码 |
| 文献数量 | 综述型“至少30篇以上”且必须有外文；其他类型“至少15篇以上” | 已加载书目少于15条（研究/设计）或30条（综述）时提醒，综述无外文时提醒；边界措辞和实际合格条件人工核对 |
| 纸张 | A4 | 输出尺寸210 × 297 mm |
| 边距 | 上下2.54 cm，左右2.8 cm，左装订线1 cm | 暂按左3.8 cm、右2.8 cm、上下2.54 cm实现 |
| 页眉与页脚 | 页眉1.5 cm、页脚1.75 cm；右下角页码 | 按纸边位置解释并检查 PDF，Word 参数不直接等于 LaTeX 的 headsep / footskip |
| 页眉标志 | 居中，4.5 × 0.9 cm | 使用手册中紧邻该要求的字标图片；检查实际位置及正文间距 |
| 打印扉页 | 题目二号黑体，其他三号宋体加粗 | 暂拟打印扉页；缺完整空白底稿，不能作为正式封面承诺 |

## 未决事项与当前解释

| 未决事项 | 当前处理 | 正式使用所需核实 |
| --- | --- | --- |
| 手册适用届次 | 配置名固定为 `cueb-2024` | 2026年及其他届次是否继续采用该要求 |
| 统一封面、完整扉页 | 自动生成暂拟打印扉页；允许 `cover-file` 插入 PDF | 学校/学院下发的空白底稿，是否需要同时保留两页 |
| 图表公式编号冲突 | 以明确文字条款为先，默认全文连续 | 是否要求按一级标题编号 |
| 装订线 | 左侧2.8 cm之外叠加1 cm，得到3.8 cm | 学校是否将装订线包含在左边距内 |
| 行距 | 小四正文，基线18 bp | 用确认的参考页校准 Word 1.5倍行距的实际视觉效果 |
| 页眉页脚基准 | 按纸边到元素的距离解释 | 用确认的成品页检查距离的测量基准 |
| 前置页页码 | 封面和扉页无页码；摘要起阿拉伯数字连续编号 | 是否另用罗马数字、目录是否参与连续计数 |
| 一级标题换页 | 类不强制，示例可手动清页 | 学院是否要求每个一级标题另起页 |
| 重复引文 | 每次生成新的完整脚注，书目去重 | 是否允许或要求缩略引文 |
| 网络发布时间缺失 | 不把访问日期伪造为发布时间；缺发布年份时给出提醒 | 能否接受无日期，或改引有明确日期的版本 |
| 学院扩展 | 默认 `artificial-intelligence`，设置学院名称为人工智能学院；保留 `general` | 目前沿用校级手册，收到学院补充文件后再增加格式覆盖 |

以上事项不阻止预览与内容写作，但影响正式合规结论。未经逐项核实，不把预览版标记为“官方”“最新标准”或“已经全面合规”。

## 人工核对清单

- 检查正式字体下的每一页，而非仅检查预览 PDF。
- 测量边距、页眉字标尺寸和页脚位置；确认长题目、关键词、脚注没有重叠。
- 检查跨节图表公式与脚注的连续编号、重复引用和中文拼音排序。
- 检查跨页表重复表头、参考文献长网址和缺失元数据。
- 清除全部占位身份、示例文字和人工构造数据，再核对最终字数与文献数量。
- 以当前适用的学校/学院要求确认封面、装订线、编号方案及最终提交文件。

## 自动检查的范围

v0.1.1 采用 Python 集成检查验证关键行为，尚未引入 l3build。字数、摘要篇幅和关键词数量需人工核对。文献数量和综述外文文献检查只给出提醒，按已加载书目计数，不构成对来源质量、篇数边界或正式合格条件的自动判定。页面与正式字体核对也不能仅靠自动测试替代。

按节编号时，附件中的图、表和公式使用 `附1.1` 等编号，避免与正文第1节的对象重号；全文连续模式下，附件对象继续沿用全篇序号。
