# 首都经济贸易大学本科毕业论文 LaTeX 模板设计方案

> 2026-09-20 实施更新：用户将当前使用范围指定为人工智能学院；v0.1.1 默认选择 `artificial-intelligence` 并预设学院名称，保留 `general`。以下为最初设计记录，学院版式继续沿用现有校级依据。

日期：2026年9月20日。状态：供评审的设计方案，尚未实现或验证编译结果。

建议项目名为 `cueb-undergraduate-thesis`，文档类名为 `cuebthesis`。面向全校本科毕业论文与毕业设计，保留学院配置。根据用户选定的方向，以 ThuThesis 为主要工程参考，采用其统一配置、内容分文件、独立文献样式、自动测试与发布包的组织方式，基于成熟中文排版组件实现首经贸本科规则。

“标准”的含义是逐条落实明确版本的学校要求，并提供可检查的样例。项目应标注“社区维护，依据所附2024届手册中的本科撰写要求”，在获得新的规范前，不宣称为学校官方模板或最新年度认证模板。

## 1 依据与范围

主要依据为用户提供的《4-本科毕业论文(设计)指导与评审手册+格式撰写要求（参考）.docx》，封面标注“二〇二四届”。采用其中《首都经济贸易大学本科毕业论文（设计）撰写要求》及末尾“内容—示例—要求”表作为规范来源。手册中的学生资料、已填写的开题报告和指导记录是个案材料，不作为模板默认内容。

规范优先级为：经确认适用的当届学校文件、经确认的学院补充文件、本手册明确条款、经记录的模板设计默认值。学院配置中的每项覆盖都应记录出处与适用范围；与学校规定冲突时必须显式标出，不能默默改变通用版本。

第一版交付论文排版模板、最小写作工程、完整排版示例、使用说明和格式核对表。开题报告、指导记录、评阅意见和答辩记录属于独立流程表单，后续可扩展为单独模板。全英文论文的完整本地化作为后续扩展，第一版完整覆盖中文正文与中英文摘要。

## 3 规范到模板的对应关系

下表引用手册的章节标题作为定位，不推测 Word 渲染页码。

| 项目 | 手册要求 | 模板设计 |
| --- | --- | --- |
| 组成顺序 | 封面、中英文摘要、目录、正文、参考文献、附件、致谢；另对扉页有要求 | 提供统一入口，封面与扉页分别处理；附件、图表目录按需启用 |
| 正文字数 | 中文一般8000～10000字；外文一般5000～10000单词 | 字数检查作为提醒；中文正文、摘要与文献分别统计，不冒充学校系统计数 |
| 中文摘要 | 约300～500字；关键词3～5个，中英文摘要页最下方另起一行 | 独立摘要环境，关键词置于摘要页下部；超长摘要提示检查分页 |
| 标题层级 | `1`、`1.1`、`1.1.1`；一般不超过三级；左齐，编号后空一个汉字距 | 一级使用 section，二三级依次对应；间隔按汉字宽度设置 |
| 标题字体 | 一级黑体小三；二级黑体小四；三级宋体小四 | 统一由文档类控制，不靠学生手动加粗或调字号 |
| 正文字体 | 中文宋体小四；英文 Times New Roman 12磅；两端对齐，首行缩进两字 | 指定中文、拉丁字体与首行缩进；保留字体配置入口 |
| 行距 | 1.5倍 | 建立与参考排版相核对的行距定义；不能假定 LaTeX 的倍率与 Word 一致 |
| 摘要、目录、参考文献 | 名称黑体小三，内容宋体小四 | 统一无编号标题样式，目录自动生成 |
| 图表题 | 图下、表上，居中；宋体五号；编号与题名空两格 | 固定位置、字号与明确宽度的间隔 |
| 公式 | 编号带圆括号，靠右，无虚线 | 自动计数、交叉引用，支持多行公式 |
| 引注 | 当页脚注；正文标记为上角标方括号数字；全文连续编号；脚注宋体小五 | 专用脚注引文命令，脚注计数不随页或一级标题重置 |
| 文末文献 | 中文在前、外文在后；组内按作者拼音或字母；GB/T 7714—2005；可不标起止页码 | 2005著录样式加排序规则，默认保留已有文献页码 |
| 文献数量 | 综述型“至少30篇以上”且必须有外文，其他类型“至少15篇以上” | 设置论文类型以生成提醒；边界措辞需按学院口径核对，不据此自动判定合格 |
| 纸张与边距 | A4，上下2.54 cm，左右2.8 cm，左侧装订线1 cm | 暂按左侧正文距纸边3.8 cm、右侧2.8 cm解释，单独保留装订线参数 |
| 页眉页脚 | 页眉1.5 cm，页脚1.75 cm；页码右下角；居中学校标志4.5×0.9 cm | 按纸边到实际元素位置校准，避免直接把 Word 参数照填为 headsep/footskip |
| 封面与扉页 | 封面用统一格式，项目手写；扉页打印，题目二号黑体，其他三号宋体加粗 | 支持学校空白封面底稿与打印扉页；不把手册封面当作论文封面 |

## 4 必须显式处理的差异

### 图表公式编号

手册正文要求全文连续编号，如“图1、表1、公式（1）”，末表却出现“图1.1、表1.1、（3.2）”。默认采用明确的文字条款，即全文连续编号，并提供“按一级标题编号”选项。手册自身的冲突写入规范核对表；没有学院依据时不将另一种方式描述为同样已确认合规。

### 页面参数

手册文字规定左侧装订线1 cm，但所附指导手册 DOCX 的实际节设置中装订线为0。该文件本身也不是论文成品，不应直接复制其页面样式。按文字要求设计，制作基准页后核对装订线是否在2.8 cm左边距之外叠加。

“页眉1.5 cm、页脚1.75 cm”是 Word 页面设置语义，与 LaTeX 页眉间距参数并非一一对应。验收时测量 PDF 上的实际位置，并检查0.9 cm高标志与正文之间是否重叠。

### 尚未明确的细节

手册没有完整指定页码起算范围、前置部分是否用罗马数字、一级标题是否另起页、标题段前段后距离等。初版暂定封面扉页无页码，中文摘要起使用阿拉伯数字连续编号，正文一级标题不强制另起页；这些均标为设计默认值，允许学院覆盖，不冒充原文要求。

手册未提供可确认的论文封面和扉页完整空白版式。正文规范原型可以先完成，正式发布前需用学校下发的封面与扉页底稿核对。所附文件中的指导与评审手册封面不能替代这一依据。

## 5 引文与参考文献设计

采用 XeLaTeX、biblatex、Biber。学生维护一份 `.bib` 文献库，模板分别生成当页脚注和文末文献表。

脚注编号按每次注释出现的次序递增；重复引用同一文献时，默认生成新的脚注号，并完整列出该次引用信息。文末文献按来源去重，再进行“中文在前、外文在后，组内作者拼音／字母排序”，文末序号与脚注号独立。手册没有要求二者一一对应，也未规定重复引文的省略方式，因此该策略明确标为设计默认值。

脚注按手册的期刊、图书、网络文献示例单独适配，保留本次引用的具体页码。不要把文末“可不标起止页码”误用到脚注。普通说明性脚注与文献脚注共用全文连续计数，避免出现重复编号。

上游 `gb7714-2005.bbx` 已核实存在，但它本身不能保证实现学校的全部要求；源码还设置了 `url=false`。适配层应特别验证网络文献的作者、题名、网址与发布时间是否输出，不能仅加载样式就宣布合规。

文献元数据明确区分中文与外文，以 `langid` 等字段承载；中文作者提供可覆写的拼音排序键，处理多音字、团体作者和中英文混合姓名。可利用 Biber 的排序能力，但最终要用已知顺序的样例验证，不能默认 Unicode 排序等于拼音排序。日俄等非拉丁文字的外文作者保留显式转写排序键入口。

除正文引用外，手册允许列出对写作有帮助和启发的文献。模板提供显式加入文献表的入口，默认不把整个 `.bib` 库全部输出。

## 6 工程结构与学生使用方式

建议结构如下，这是设计结构，并非已创建的模板项目。

```text
cueb-undergraduate-thesis/
  cuebthesis.cls                 本科文档类与公共接口
  config/
    cueb-2024.def                手册明确要求和有标记的默认值
    colleges/                   有来源依据的学院覆盖配置
  styles/
    cueb-footnote.cbx            学校脚注引文样式
    cueb-bibliography.bbx        学校文末著录与排序适配
  assets/                       学校标志及来源说明
  main.tex                      本科论文编译入口
  cuebsetup.tex                 基本信息与用户配置，借鉴 thusetup.tex
  data/                         摘要、正文、附件、致谢
  figures/                      论文图片
  ref/refs.bib                  学生文献库
  examples/                     完整排版示例
  docs/                         使用说明、规范映射与差异记录
  testfiles/                    关键行为与基准 PDF 检查材料
  build.lua                     l3build 回归测试配置
  latexmkrc                     一键编译配置
  utils/create_release.py       发布工程打包
  .github/workflows/            自动编译与发布
  UPSTREAM.md                   借鉴及代码复用来源
  CHANGELOG.md                  模板变更与规范版本变化
  README.md
  LICENSE
```

文档类基于 `ctexart`，贴合三级阿拉伯数字标题；封面、摘要、目录等由专用命令封装。全校规则集中在版本配置中，学院配置只记录差异，不复制整套文档类。正文内容不应依赖某个学院专用命令。

学生通常只修改四类内容：基本信息、章节正文、图片、文献库。通过单一配置接口选择规范版本、学院、论文类型、字体方案与编号方式。默认加载通用配置；学院名称作为封面信息与学院配置选择分开，避免只因填写学院名称就隐式改变格式。

第一版提供一个短的最小工程和一个完整排版示例。完整示例覆盖数学公式、三线表、跨页表、图片、交叉引用、中英文文献和附件；写作说明给出实证研究、系统设计、文献综述三种可选章节组织，不强制所有专业采用同一论文结构。

ThuThesis 使用 `.dtx/.ins` 管理源码并生成 `.cls`。本项目首版直接维护 `.cls` 和独立说明，便于核对学校条款；若后续需要 CTAN 发布和完整代码文档，可再迁移到该组织形式。发布包始终包含能直接使用的 `.cls`，学生不需要自行生成文档类。

## 7 字体与编译体验

编译统一使用 XeLaTeX，配合 Biber，由 latexmk 自动完成必要轮次。本地支持 TeX Live／MacTeX，提供 Overleaf 导入包及明确的编译器、TeX Live 版本设置。首版只承诺经过验证的一套版本组合。

区分提交字体方案与预览字体方案：提交方案要求实际宋体、黑体和 Times New Roman；预览方案可用 TeX Live 可分发字体，使新用户先编译成功。预览字体产生的断行、字宽和分页可能不同，不能视为提交版已通过格式核对。

提交方案缺失必要字体、缺失必填信息、引用键未解析，应给出明确错误或阻止发布验证通过。标题过长、摘要或文献数量不符等产生可读提示。字体文件不默认随仓库分发；使用者可配置自己合法可用的字体。

一键编译之外，README 用一页说明“下载—填写信息—编辑章节—添加文献—编译 PDF—提交前核对”。错误说明覆盖缺字体、忘记运行 Biber、图片路径错误和参考文献缺字段。

## 8 验收与交付

验收先检查规范，再检查工程可用性。关键案例包括：跨两个一级标题仍连续编号的脚注与图表公式；同一文献重复引用而脚注号继续递增；中文作者拼音排序；中文组先于外文组；网络脚注完整输出网址和日期；长题目与长摘要不遮挡其他内容。

页面验收使用固定版本和固定字体生成基准 PDF，核对A4尺寸、实际边距、装订线、页眉标志大小、右下角页码和典型页面。行距与字号用学校参考页校准；只检查编译成功不足以证明格式正确。

自动编译检查缺字、未解析引用和交叉引用、超出版心等问题；对人工认可的基准页做视觉回归。预览字体的自动编译只证明预览链路可用，正式字体另行验收。

学院配置至少用一个有依据的覆盖项验证隔离：启用时改变指定行为，关闭时恢复通用规则。没有来源的学院配置不预填虚构规则。

最终交付建议包括 GitHub 源码仓库、可下载的本地／Overleaf 工程包、完整示例 PDF、快速入门、逐条规范核对表与版本说明。只有全部硬性要求通过、规范冲突形成明确处理记录后，才发布1.0正式版；此前标记为依据2024手册的预览版。

## 9 实施顺序与发布前输入

1. 固化规范映射，明确全文编号、装订线等歧义的默认处理；确认适用年度与封面底稿。
2. 完成页面、字体、标题、摘要、目录和打印扉页原型，优先审阅典型页面。
3. 完成脚注与文末参考文献适配，验证排序、重复引用和网络文献。
4. 加入学院配置、最小工程与完整示例，完成本地及 Overleaf 验收。
5. 整理说明和发布包，记录代码版本、规范版本、编译环境及字体条件。

当前材料足以设计并启动正文规范原型。正式发布前仍需核实：当届是否继续采用该手册要求；学校论文封面和扉页底稿；编号冲突与装订线的最终解释；如要发布具体学院配置，则需要对应学院文件。这些输入影响正式合规结论，不妨碍先完成通用模板原型。
