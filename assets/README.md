# 校名字标及外部封面

`cueb-logo.png` 提取自用户提供的二〇二四届《4-本科毕业论文(设计)指导与评审手册+格式撰写要求（参考）.docx》中的 `word/media/image2.png`。该图片紧邻规定页眉学校标志为4.5 × 0.9 cm的要求段落，因此作为页眉字标来源；它不是从其他网页临时重绘的标志。

原图为495 × 122像素，宽高比约4.06∶1。固定为4.5 × 0.9 cm会压扁圆形校徽；当前版改用4.5 cm宽、保持原比例，实际高度约1.109 cm，并预留6 mm页眉与正文间距。这是为避免图片变形所做的版式调整，不是对手册尺寸的重新认定。校名字标相关权利归原权利人所有，代码的 LPPL 许可证不覆盖该标志，也不表示学校授权或认可本模板。该资源只用于说明所附手册要求的论文页眉。

原始手册含学生资料，整个 DOCX、其中学生信息、已填写报告与指导记录均不随项目分发。项目没有附带可确认的正式论文封面底稿。若使用者取得合法可用并经确认的封面 PDF，可自行放入本目录，再设置 `cover-file={assets/approved-cover.pdf}`；请先检查 PDF 是否包含不应公开的个人信息。
